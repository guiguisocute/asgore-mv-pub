# ASGORE · 音乐剧 MV

中立线国王战的同人音乐剧：画面是原作的 UT 战斗，编舞踩在 `music1.mp3`（Bergentrückung）与 `music2.mp3`（ASGORE）的网格上。无框架、无打包器，浏览器直接打开就能播。

基调是**悲壮的英雄史诗**。他不想打，却必须赢。

UNDERTALE 及其角色、画面、音乐版权归 [Toby Fox](https://undertale.com/) 所有。本仓库是非商业同人作品。原作代码以 [MIT](LICENSE) 发布；素材与原曲的权利仍归权利人。

## 播放

需要两首原曲文件（仓库里已放好 `music1.mp3` / `music2.mp3`）和现代浏览器（WebGL2）。

```bash
python tools/serve.py 4176
# 打开 http://127.0.0.1:4176/
```

也可以直接用 `file://` 打开 `index.html`。

- 空格 / Z：播放暂停
- ← / →：快退快进
- D：调试信息
- 点底部进度条：跳转

## 成片

五幕，约 4 分 10 秒（`src/util.js` 的 `T.m1 / T.cut1 / T.m2 / T.mus2End / T.end`）。

| 幕 | 视频时间 | 声音 | 画面 | 内容 |
| --- | --- | --- | --- | --- |
| 一 · 结界 | 0 – 23 s | 静默，只有音效 | 体素（看起来是 2D） | 「* 这就是结界。」他转身，七个容器升起，「* 准备好了？」 |
| 二 · 囚笼 | 23 – 40 s | music1（8 小节） | 体素 → 2D | 镜头斜切显出走廊的深度 → 深处的黑压过来 → 白收成锁住红心的框 → 火焰、容器、长袍、HUD |
| 三 · 开战 | 40 – 61.6 s | 静默 | 2D | 原作旁白四句、气泡「人类……很高兴认识你。」「再见。」→ 拔戟、一击粉碎「仁慈」 |
| 四 · 决战 | 61.6 – 216 s | music2（74 小节） | 2D（两处体素窗口） | 王之火 → 六魂 → 蓄满 → 坠落 → 回忆 → 跃上容器 → 最后的「战斗」 |
| 五 · 终幕 | 216 – 250 s | 静默 | 2D | 跪下、「查看」、「仁慈」飞回、等待、友谊颗粒、黑场 |

## 规则

- 中立线，LV 1，HP 20，名字 Frisk。
- 交谈无效之前只用「行动 · 交谈」和「物品 · 奶油糖果派」，不选「战斗」。
- 红心只在第 19 小节（黄魂决斗，20 → 14）和第 52 小节（全力一击，14 → 1）受伤；其余擦身而过（`tools/check.cjs` 校验）。
- 橙色只在心移动时穿过，青色只在心静止时穿过；绿魂给护盾，紫魂只能沿线走，蓝魂有重力。
- 「仁慈」在第三幕被砸碎，碎片留在按钮位，第五幕飞回重组。
- 容器全片在场。**灵魂从不离开容器**：他借用力量时，一条那颗灵魂颜色的光带从容器连到三叉戟。他从不吸收它们。
- 战斗中他的脸是原作那张战斗的面具：不闭眼、不换表情、被打中也不晃。脸只在跪下之后照原作换。
- 他不流泪。不忍靠不直视、别过头、手。
- 一个画面一个机位。

## 情绪

核心是**「他不想打，却必须赢」**。观众情绪最高的时刻，是那层王的盔甲裂开、底下那个温柔的园丁露出来的一瞬间。

> 每一次华丽的攻击背后，都藏着一个他「不忍」的细节；镜头让观众看见红心看不见的东西。

镜头离他的脸有多近，就是情绪的刻度：0–15 看他像看 Boss；16–39 去看那些容器；40–51 镜头失去分寸；52 一切停住；53–59 第一次温柔；60–73 一次比一次更近。

他从不直视那颗心。整幕他都躲着你的目光，只在两个时刻真正看向你：第 52 小节他「赢了」的那一刻，和最后跪下的时候。一双浇花的手握着三叉戟：交谈①时发抖（原作原话「他的手颤抖了一下」）；每次借用灵魂，他松开一只手、摊开爪子伸向那个容器，像捧一朵花那样接住它的光。

几个打穿人的瞬间：第 14 小节青色戟尖刺向镜头的看破；第 52 小节七彩全力一击把心打到 1，黑场里杀你的人用他的声音说「你现在还不能放弃……Frisk！」；派的香味与三幅家的画；孩子们收回力量；最后一击落在音乐的最后一个音上，然后是寂静；第五幕「查看」打出「* 一位父亲。」

## 画面

主体是 **960×540 的 2D 像素世界**（导出 1920×1080，整数 2 倍、最近邻）。原作 640×480 战斗布局放在 (+160, +30)：上方艾斯戈尔、中间战斗框、下方 HUD。精灵按原作的 2 倍、整数缩放。**战斗框内部永远是纯黑。**

背景从第二幕长出来：结界房间的白收拢成战斗框的边，房间退到画面背后，成了一圈套一圈的同心矩形。由远到近：门里的光（第三幕旁白之后慢慢从冷白走向黎明的金）、压暗的长廊、从黑暗里升起来的火星与小火苗、原作的橙色余烬。背景亮度有上限，任何时候都不能抢战斗框的戏。他借用哪一颗灵魂，走廊就变成那个孩子的世界。

2D 世界分成四张平面，由一台真正的 3D 相机拍（`src/post2d.js`，HD-2D）：

- 最远：走廊、门里的光、余烬（深 900）
- 石台、容器、火星（深 170）
- 他、三叉戟、光带（深 110）
- 战斗：框、弹幕、HUD、心（深 0）

相机在「家」时画面与原作逐像素一致。一俯一仰、一转、一推，各层就互相滑动。换机位用硬切，落在乐句开头或重击上。心在躲的时候，它和威胁它的东西必须在画面里、看得清。

体素只用来制造意外：第一幕到第二幕第 4 小节，结界房间是体素，相机站在管道轴线上时看起来就是原作的 2D；绿魂第一人称格挡、蓝魂 FEZ 各开一个不超过 4 小节的窗口。进出要么与 2D 构图一致，要么是一次有理由的硬切。

白色可以正常使用。要避免的是过强的发光：辉光阈值高、强度低。

## 六魂

每颗灵魂 = 一件遗物 + 一条原作规则 + 一种 2D 里好看的机制 + 这一段的节奏。考据见 `asset/six-soul.md`（游戏正文与系统文本）。遗物画在 `src/props.js`。

| 颜色 | 特质 · 遗物 | 机制 |
| --- | --- | --- |
| 黄 | 正义 · 空枪、牛仔帽 | 射击模式。Dead Eye：世界停成旧照片，标记打在心走过的路上，子弹追着它刚才在的地方。第 19 小节决斗，心也瞄准了他，却始终没有开枪 |
| 绿 | 善良 · 平底锅、脏围裙 | 体素第一人称：立方体笼子，四面是厨房，绿色玻璃盾迎挡他的火 |
| 紫 | 毅力 · 破笔记本、云雾眼镜 | 陷阱模式。两列纸页、原作的负面词、翻页、一条条线被划掉；最后划掉「凶手」，写下「对不起」 |
| 蓝 | 正直 · 芭蕾舞鞋、旧舞裙 | 跳跃。八音盒；FEZ：正面走不通的方块，侧面看是一道台阶 |
| 橙 | 勇敢 · 强韧手套、头巾 | 拳台。框的边就是弹弓；心迎上去振刀，把拳套弹回去 |
| 青 | 耐心 · 玩具刀、褪色丝带 | SUPERHOT。心一停世界就停；丝带只在心动时飞，刀只在心停时飞 |

64–70 反过来：Frisk 跳上罐子，每颗魂照雪镇「滚球」旗子文案的方式赢 —— 橙「拳头朝前冲过一切障碍」，黄「准确的射击」，绿「关心与照料」，青「等待，然后一记锐利的攻击」，蓝「跳跃与旋转」，紫「即使觉得被困住，你也记下了笔记」。第 71 小节红旗的六个词进入心里：勇敢、正义、正直、善良、毅力、耐心。

他借用哪一颗，背后的走廊就变成那个孩子留下东西的地方（`src/worlds.js`）：日落的边疆、厨房的灶台、云雾里的书库、瀑布的许愿之间、雪镇的暴风雪、秋天的遗迹。世界没有人。光带断开时，他的火星从下往上把它烧掉。

打在他身上的每一击共用一套语法（`src/blow.js`）：蓄 → 命中 → 顿帧 → 黑白冲击帧 → 那颗魂颜色的暗场加上大厅的同心矩形 → 松开时环冲出画面，火星、尘土、披风的风，伤害盖章。他自己一动不动，力由世界和镜头接住。

## 音乐

`tools/analyze_music.py`（librosa）把分析结果写入 `src/analysis.js`。速度在起音包络上搜索恒定 16 分网格，再对残差做线性回归消除漂移。相位用非居中短窗的起音通量（居中 STFT 会报早 20–40 ms）。

| 项目 | music1 · Bergentrückung | music2 · ASGORE |
| --- | --- | --- |
| 速度 | 113.01 BPM 恒定 | 114.85 BPM 恒定 |
| 16 分 / 拍 / 小节 | 0.1327 / 0.5309 / 2.1237 s | 0.1306 / 0.5224 / 2.0897 s |
| 长度 | 8 小节音乐 + 尾部静默 | 74 小节（最后一个音约 153.6 s） |

ASGORE 的段落：主题 A（0–15，每 4 小节开头两声管弦重击）→ 主题 B（16–23）→ 进行曲（24–39）→ 上升（40–43）→ 高潮（44–51）→ 坠落（52）→ 八音盒（53–59）→ 回归与终章（60–73）。

编舞落在这个网格上：`T.at(小节, 拍, 16分)`。每一段的机制从这一段的节奏里长出来。

## 代码

零框架的 vanilla JS，挂在 `window.MV` 上。`index.html` 按顺序加载 `src/*.js`。时间轴是无状态关键帧：任意时刻都能单独画出那一帧，所以能拖进度条，也能离线导出。

```
index.html            播放器
music1.mp3 music2.mp3 Bergentrückung / ASGORE
src/analysis.js       音乐分析（生成）
src/assets.js         精灵、战斗 UI、音效（生成）
src/assets_story.js   原作棕褐色故事画（生成）
src/glyphs.js         点阵字（生成）
src/util.js           时钟 T.m1 / T.at / T.at1
src/engine.js         无状态关键帧
src/timeline.js       共用轨道与编舞工具
src/main.js           播放、音效、导出 API
src/tl_act1.js … 5.js 五幕编舞（第四幕拆成 a–e）
src/fight.js          弹幕、碰撞、菜单、光带、预警
src/kingfire.js       他的火、火链、火雨、躲避规划
src/worlds.js         六个世界
src/blow.js           打在他身上的打击语法
src/finale.js         回忆、全力一击、跪地
src/flat.js           2D 布局与帧合成
src/post2d.js         多平面 3D 相机与后期
src/stage.js          常驻 2D 角色与布景
src/vox.js            WebGL2 体素
src/corridor.js       结界房间的光波（生成）
```

## 工具

播放本身不需要 Node。导出和碰撞校验需要 [Playwright](https://playwright.dev/) 与 [ffmpeg](https://ffmpeg.org/)。

```bash
npm i
node tools/check.cjs                  # 弹幕校验（除编排好的受伤时刻外，子弹碰不到心）
node tools/frames.cjs --gpu 12        # 渲染某一秒的静帧
node tools/render.cjs --gpu --vcodec=h264_nvenc --workers=2
# 默认导出 dist/mv_1080p60.mp4，范围是整片 T.cut
# --t0=0 --t1=60 --out=dist/preview.mp4 可切一段
```

`--gpu` 用本机 GPU（Windows 上是 D3D11）。默认 SwiftShader。混音是两首音乐加上时间轴上的音效，48 kHz 立体声。

重新分析音乐、切精灵表、烘焙走廊光波需要 Python 3.12、ffmpeg、Pillow、librosa：

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/Scripts/python.exe numpy scipy librosa pillow
python tools/analyze_music.py         # -> src/analysis.js
python tools/import_assets.py         # -> src/assets.js（精灵表已在 asset/；完整音效包需自行放置）
python tools/import_story.py          # -> src/assets_story.js
python tools/make_font.py             # -> src/glyphs.js
```

`src/analysis.js`、`src/assets.js`、`src/corridor.js`、`src/glyphs.js` 已经生成好，日常播放不必重跑。
